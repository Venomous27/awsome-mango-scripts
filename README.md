# Mango Scripts

This repository is a collection of community/user-submitted scripts for Mango WM.

Maintainers do not check or review the scripts. They only accept the pull requests submitted by users who create them. You are advised to check the script yourself before using it.

## How to use a script

All scripts are stored in the `scripts/` folder, with each script in its own folder.

This repository uses a folder-based structure, meaning each folder inside [`scripts/`](scripts/) is essentially a self-contained repository. It contains the script, a README, an example config, and any other required files.

Simply download the folder containing the script you want, and you're good to go.
