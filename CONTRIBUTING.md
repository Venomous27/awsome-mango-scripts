# Rules

- Make sure you include a `README.md` with a proper guide on how to use your script.
- All files must be stored inside a folder named after your script.
- If your script requires config files or other additional files, make sure you include example configs where needed.
- Don't update anything else except adding your own folder and updating the README table with your own entry.
- You can always open an issue for things like changing the README format or requesting other changes.

# How to Submit

- Fork this repository.
- Upload your script folder inside `scripts/`.
- Update the README's **Available Scripts** table by adding:
  1. Script name
  2. Description
  3. Author (your username)
  4. Link to the script: `[Click Here](path/to/script)`. Keep "Click Here" as it is to maintain formatting. 
- Commit your changes and open a Pull Request.

**If a maintainer accepts your Pull Request, your script will be added to the main repository.**
